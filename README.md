# Slider Fun

A slider project featuring cool CSS animations and effects.

## Features

- Animated slide transitions
- Creative visual effects with CSS
- Smooth and interactive UI

## Tech Stack

- HTML5
- CSS3 (Animations & Transitions)
- JavaScript (Vanilla)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/ayushpratap27/SliderFun.git
   ```
2. Open `index.html` in your browser.
